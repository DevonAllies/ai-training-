How does my teammate get the .ibt file? In iRacing, press Alt+L in the car to start telemetry logging (or turn it on permanently in the iRacing options), drive the lap, then send the file from Documents\iRacing\telemetry\ – one file per session, named after car, track and date. SimCoach finds every lap in it and picks the fastest clean one. iRacing's .blap/.olap ghost files use a private format that can't be read reliably, so they aren't supported.

Garage 61 only shares laps from you, your teammates and drivers you follow. Telemetry of other drivers requires a Garage 61 Pro plan.

      Garage 61

      Create a personal access token on garage61.net (Settings → Developer → Personal access tokens) with the driving_data permission, then paste it here. It is stored only on this PC.

      App

      In-game overlay

      A small always-on-top window over iRacing (run iRacing in borderless windowed mode). Drag to move, mouse wheel to resize, right-click for options. A browser version for OBS or a tablet is at /overlay.

      Voice coach

      One short reminder before a corner, based on what you did there last lap ("C3, brake later") – not a running commentary. Uses Windows text-to-speech; the browser overlay can also speak (/overlay?voice=1).

      Training features

      Switch off what you don't want – it disappears from the dashboard, overlay and voice.

      Tablet / phone

      Use a tablet or phone next to your rig as a second screen. It must be on the same home Wi-Fi. Devices on your network can use the coaching screens but can't change settings or delete anything.

      Restart SimCoach to apply.

      Updates

      SimCoach is one self-contained app (Python and all libraries are built in). It checks GitHub for new versions, verifies the download and installs it for you – never while you're on track.
